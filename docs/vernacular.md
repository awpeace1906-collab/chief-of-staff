# Vernacular

Chief of Staff borrows the language of a head of state's staff and protective detail. The terms below are used across the docs, prompts and app text. Code identifiers and stored data keys don't change (`owner` in settings, message senders and function names stays as is), so renaming a term never breaks a memory repo or a database.

## In use

| Term | Means | Was |
|---|---|---|
| **Principal** | The person the agent serves: the app's user. Everything is planned around the principal's day, position and commitments. | owner, user |
| **Chief of Staff** | The app: the interface between the principal and their agent. | |
| **Callsign** | The agent's name, which the principal chooses (the alias). It can be changed; the agent's permanent id never does ([memory.md](memory.md)). | alias |

## Proposed

These aren't used yet. Each one becomes "in use" once the principal agrees to it, and then the docs, prompts and app text change together.

| Term | Would mean | Today |
|---|---|---|
| **The Book** | The evening package for tomorrow: first movement, what to bring, what's due, coverage. A President's staff hands over "the Book" each night. | Tomorrow card, evening setup |
| **Daily brief** | The morning brief, as in the President's Daily Brief. | Morning brief |
| **Advance** | Prep for an event or trip: route, timing, parking, badge, contacts, checked before the day. | Prep items, binders |
| **Movement** | Any time the principal travels: a drive, a flight leg, a transfer. "Wheels up" and "arrived" are a movement's status. | Trip legs, drive times |
| **Position** | Where the principal is right now: phone, then trip, then home ([location](features/location.md)). | Whereabouts, location |
| **Protectees** | The other people in the principal's household, whose coverage the agent watches (partner, children). | Household, divisions |
| **Detail** | Everyone covering the protectees at a given time: partner, nanny, family. A coverage gap is a hole in the detail. | Coverage |
| **Codenames** | Short names for the principal and protectees, used in texts and notifications. They're chosen by the principal and kept in memory, never in the core. | Names |
| **Situation Room** | The Decide list: choices only the principal can make, with options and a deadline. | Decisions |
